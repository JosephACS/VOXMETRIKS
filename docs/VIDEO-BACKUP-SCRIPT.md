# Video backup script (demo)

Use if live stack fails. Record once on a healthy machine. **No passwords on video title cards.**

## Length

7–10 minutes total (aligned with live 5-account flow).

## Suggested chapters

| # | Time | Scene | On screen |
|---|------|-------|-----------|
| 1 | 0:00–0:40 | Cold open | Home / discover as `listener.free` — search + play |
| 2 | 0:40–2:30 | Artist publish | `demo.artist` → new release → upload audio/cover → rights → submit → `/catalog-review` approve/publish |
| 3 | 2:30–4:00 | B2C upgrade | `listener.free` → plans → Premium Individual → mock pay → invoice |
| 4 | 4:00–5:30 | Household | `household.owner` → household members (or cut if time) |
| 5 | 5:30–7:30 | B2B + royalties | `organization.owner` / `finance.manager` or `demo.business` → CRM snippet → billing → `/royalties` mock settlement banner |
| 6 | 7:30–8:30 | Close | Architecture one-liner + “all payments simulated” |

## Capture tips

- 1080p, browser only (no desktop icons)
- Mask any env panels; never zoom into `.env`
- Narration: Spanish or bilingual as needed for the defense
- Export MP4 to USB labeled `VOXMETRIKS-DEMO-VIDEO`

## Live vs video

Prefer live; switch to video only after emergency checklist (`docs/DEMO-EMERGENCY-MODE.md`).
